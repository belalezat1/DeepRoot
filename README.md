# Deeproot

Deeproot carries client context from emails into a cited meeting report and a reviewed Linear issue. Built for GirlHacks 2026 (ADP and Avanade tracks).

- [PRD](docs/PRD.md): what we're building and the Acme demo scenario
- [Build plan](docs/BUILD_PLAN.md): architecture, shared contracts, API, timeline, and teammate roles

| `web/` | React/Vite frontend | Teammate 2 |

| `demo/` | Fictional fixtures and meeting script | Teammate 4 |
